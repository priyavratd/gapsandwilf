# Structure of Gaps and Generalized Wilf’s Conjecture

This repository contains the SageMath code used for the computational experiments in the paper:

**Structure of Gaps and Generalized Wilf’s Conjecture**

by Om Prakash Bhardwaj, Carmelo Cisto, and Priyavrat Deshpande.

## About the repository

The notebook contain computations related to the structure of gaps in generalized numerical semigroups. In particular, they provide computational tools to construct the semigroups considered in the paper, enumerate their gaps, and examine the corresponding genus and other relevant quantities.

The computational experiments were used to explore examples, identify patterns, and motivate some of the results proved in the paper. The mathematical statements in the paper are established by proofs; the computations are intended as supporting and exploratory material.

## Requirements

The computations were performed using **SageMath [10.4]**.

To run the notebooks, open them in a SageMath environment that supports Jupyter notebooks. No additional packages are required beyond the standard SageMath installation.  

## Running the notebooks

1. Clone or download this repository.
2. Open the relevant notebook using the Jupyter interface provided by SageMath.
3. Run the cells in sequence.
